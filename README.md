# pakistan-explorer-travel-agency
Pakistan Explorer Travel Agency

A simple multi-page travel agency website built using HTML only as part of SMIT learning assignment.

Features
- Multi-page structure (Home, About, Services, Contact)
- Navigation using anchor tags
- Image sections
- Nested lists for travel packages
- Internal page linking (Back to Top feature)

Technologies Used
- HTML5

Pages Included
 Home Page
- About Us Page
- Services Page
- Contact Page

Purpose
This project was created to practice HTML fundamentals, page structuring, and navigation between multiple pages.
